- Backtests are isolated, user-triggered simulations using the shared pure signal function; they never import execution, reconciliation, learning, live committee cache or order submission modules.
- Historical committee decisions consume only source-labelled observations available before the simulated UTC day; user-started batches evaluate sequential portfolio candidates within a declared call budget, cache identical contexts and never automatically retry failures.
- Simulation results and arguments are exportable, not written to live trading records; missing historical coverage blocks certification rather than inventing prices or fundamentals.
- Autonomous catalog/data functions use owner-scoped credential SELECT and GET assets/market-data only, never trading modules; raw us_equity remains unclassified without authoritative subtype metadata, so names cannot fabricate ETF classification.
- Autonomous AI calls go only through the server ledger (ia_backtest_run/ia_backtest_chiamate via service-role RPCs): reserve before dispatch, idempotent canonical-input keys reuse completed results, uncertain/denied outcomes block the run and are never resent; runs are COMPLETE only when every eligible asset is screened and every selected candidate has a real committee verdict.
- Autonomous acquisitions checkpoint owner/period/source-scoped blocks in IndexedDB before continuing; failed or uncertain blocks are not automatically resent.
- Autonomous Alpaca readers select only the requesting owner's PAPER credentials; REAL and shared environment fallbacks are forbidden, so absent PAPER access fails closed.
- Optional monthly reserve (accantonamentoMensile) in the portfolio replay withdraws only realized net P&L from free cash at month close; metrics add the reserve back so withdrawals are not counted as losses.
- The default autonomous stock/ETF universe is the public Nasdaq Trader directory (ETF from its official flag, names may only exclude); FMP per-symbol 402 is an exclusion, while source-level 401/402/403/429 stops the scan.
